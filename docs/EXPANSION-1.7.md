# Expansion plan and review — 1.7

This release adds a bounded fruit-tree and Mediterranean garden group after the existing collection review. It prioritizes missing recognizable leaf forms and useful species accounts, while retaining natural overlap among orchard trees.

## Boundaries and next candidates

The collection now contains 126 taxa; further numerical expansion is not a release-quality criterion. Potential future modules are regional riparian willows (for example Salix fragilis s.l., S. triandra and S. aurita) or explicitly requested evergreen garden trees. These are candidates, not approved drawings: resolve taxonomic scope, gather mature-leaf descriptions/photos and identify the site need first. A willow icon must not imply identification without hairs, stipules and shoot characters.

The next priority is independent botanical feedback and actual website use. Review the current core before choosing another bounded group. The [scope](SCOPE.md) explains what “complete” means for an icon library.
